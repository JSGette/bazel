# Skyframe JVM optimization candidate ledger

Snapshot of the finite 45-direction sweep measured/reviewed through 2026-10-20.
See [the findings report](skyframe-jvm-optimizations.md) for methodology,
limitations and the current upstream recommendation. The dispositions below
preserve the experiment history; “accepted local commit” records a local saving,
not upstream approval or universal no-degradation. In particular, C39b is held.
Current recommendations in the findings report supersede any historical
upstream suggestions below. Further exploration and C44 remain parked.
