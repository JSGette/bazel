## Required projection correction

`FileStateValue.RegularFileStateValueWithMetadata.getDigest()` can expose a digest, but its `equals()` at lines 479–489 compares the entire backing `FileArtifactValue`. Equal digest and size therefore do not establish equality of the represented state. Initially support only the concrete `RegularFileStateValueWithDigest` regular-file subtype, with class/kind, size and digest algorithm/bytes. Metadata-backed values, contents proxies, special files and unbound roots remain unknown. This corrects the broader wording in the earlier proposal; the repository implementation checklist now records the restriction and a negative regression case. Directory/nonexistent and exact symlink-target projections remain subject to their typed root/binding constraints. BZL_LOAD remains input evidence, not module equivalence.

## Cache-specific coverage that the native source did not supply

`Bazel.java:88` registers `LocalSkycacheModule` in place of `SerializationModule`. `LocalSkycacheModule.beforeCommand():110–211` creates the input snapshot/session, changes cache mode, supplies a per-command client identity and retains prior roots. Its `afterCommand():261–377` finishes publication, captures retained roots, emits validation/ownership/finalization statistics and closes remote state. A graph-only callback trace does not cover all of this work or retained state. For a complete lifecycle envelope, starting before cache setup and closing after all module finalization is necessary; the existing `AfterCommandEvent` supplies the latter ordering before reset. Any uninstrumented portion stays explicit unknown cost.

`LocalAnalysisCacheClient.validatePreviouslyLoadedValue():118–150` and `lookup():175–218` invoke `LocalDependencyValidator` directly. Validation follows serialized fingerprints/witnesses, including publication admission, rather than ordinary Skyframe dependency edges. A restored configured target's observed Skyframe dependencies cannot silently be expanded into the original evaluated graph. Record restoration/retained-validation provenance and unsupported coverage separately; do not equate equal serialized fingerprints with supported typed semantic equivalence.

`SkyValueRetriever.java:74–83` already names retrieval phases, with transitions held in its context. Their stored durations and `LocalAnalysisCacheClient` lookup latency are elapsed time, not CPU. Existing validation counts, advisory component ownership snapshots and finalization phase records are useful cross-checks, but cannot replace exclusive CPU accounting, globally unique object accounting or the generous unsupported-cost bound. A narrow first collector may leave cache internals opaque, provided the model cannot treat them as zero or conclude an evaluator-wide ceiling from the supported leaf subset.

The baseline has no native multi-engine hosting contract. Initial trace work must use private SkyCache engines and a trace-off control of the same newly built source. Preserve the frozen isolated-SkyCache comparator, first-attachment distinction and source/version separation. The source is ready for a separately reviewed instrumentation patch; no build or trace result is claimed here.
